# RBT-124 test fixtures

Genomes copied from RBT-113's restored checkpoints (`scripts/durable.sh restore runs/RBT-113/{O1,Z1} rbt-113-{O1,Z1}`,
216/216) so the RBT-124 tests run without restoring anything. Founders are regenerated by
`initial_population(HOLISTIC, world.evolution_config("U", op, seed=seed), spawn_streams(seed, salt)[HOLISTIC])`, as
the RBT-121 probes do; the others are files of `<ARM>/<SEED>/<LINE>/holistic/final/`, by index in sorted order.
