# RBT-91: the weight-scale ceiling — operator step, clamp, or selection?

## The operator, read from rabbitstew/genetics.py
  weight_rate       = 0.25    probability each weight is touched per mutation
  weight_sigma      = 0.4    sd of the additive step when it is
  weight_reset_rate = 0.02   probability a touched weight is redrawn from N(0,1)
  clamp             = NONE. mutate_weights never bounds link.weight; freq is clipped to
                      (0.1, 5.0) and dims to (0.05, 5.0) in the same file, so this is deliberate.
  => per mutation, per weight: P(step) = 0.2450, P(reset) = 0.0050
  => stationary variance ~= 1 + sigma^2 * P(step)/P(reset) = 8.84, so sd ~= 2.97
     (verified directly: mean age since reset 198.9 against 199 predicted, E[w^2] 8.81, sd 2.969.
      Compare the rms column below, not sd|w|, which is the sd of the absolute value.)
