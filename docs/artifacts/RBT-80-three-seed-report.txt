## 0. The predicate, and why depth 1 is empty here

`rabbitstew.analysis.steering_terms` returns the depth-1 term -- the weight on the
DIRECT nose-to-Effector links -- as the exact gain of a four-link motif. RBT-65's
motif is not that motif. The encoding rejects a link from one wheel's nose to the
other wheel's Effector (genotype.py:496; the wheels are siblings, not neighbours),
so `scripts/genotype_motif.py` routes it through a global tanh interneuron and the
nose-to-Effector path is length TWO. Measured on the seeded founders:

| quantity | value on every seeded founder |
|---|---|
| depth-1 a | +0.000 |
| depth-1 balance (both noses wired direct) | 0.000 |
| depth-1 opposed (sign of s_L*s_R) | 0 |
| depth-2 a | +64.000 = 2w, the installed value |

So the depth-1 predicate defines no carriers anywhere, in any arm, in any seed,
and its verdict quantity is 0.000 - 0.000 = +0.000 by construction. It is reported
because it was asked for, and it is not a reading of this ticket's question.
Depth 2 is the shortest path sum that contains the installed motif; it is primary.
(RBT-87: now stated in steering_terms' docstring and round-tripped in tests/test_steering_terms.py.)
